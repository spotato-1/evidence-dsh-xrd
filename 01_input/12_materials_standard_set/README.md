# 12-Material Standard Test Set

Twelve powder XRD cases for end-to-end evaluation. Each case keeps only the raw input data and the two-column text the model receives.

| Case | Material | Source |
|---|---|---|
| Y2O3 | yttrium oxide | AutoFP standard example |
| PbSO4 | anglesite | GSAS-II official tutorial (lab Cu Kα) |
| Fluoroapatite | Ca5(PO4)3F | GSAS-II official example (lab Cu Kα) |
| CeO2 | ceria, broad + sharp | IUCr CPD Size-Strain Round Robin (synchrotron, λ = 0.6998 Å) |
| ZnO | zinc oxide nanocrystal | NIST SRM 1979 (synchrotron, λ = 0.41419 Å) |
| Fe2O3_Fe3O4_2ph | hematite + magnetite (70.5/29.5 wt%) | Zenodo 10.5281/zenodo.14959531 |
| LayeredOxide | P2 layered oxide | complex case from a real experiment |
| LayeredOxide_2ph | two-phase layered oxide | complex case from a real experiment |
| Amorphous | amorphous carbon anode | complex case from a real experiment |
| LiFePO4 | olivine LiFePO4 | complex case from a real experiment |
| FE50 | Prussian blue analogue | complex case from a real experiment |
| FE60 | Prussian blue analogue | complex case from a real experiment |
