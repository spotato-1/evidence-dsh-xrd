AutoFP 六样品一次 E2E 性能测试报告

本批次已对上传的 6 个样品各启动一次 AutoFP，所有正式调用均已结束。没有外部重新启动、换模型重跑或追加精修。最终输入、原生输出、内部循环轨迹和失败证据均已保存。本文分别报告运行完成、数值拟合和科学产物三个层次；正常退出不等同于结构解析成功。

本批次有明确的输入适配偏差。 执行者最初遗漏了 FullProf Ins=10 数据文件要求的六行文件头，前三个已启动样品少读前 6 点。没有重跑；后三个在首次启动前补齐注释头，数值未改。该偏差不能计为 AutoFP 算法失败，也使本批次不能直接作为完全统一输入条件下的论文成功率基准。

使用上传的 autofp-cli，108374496 字节，SHA-256 为 3b4c25f882c275b67e98745e2f95e60a6f613d14730b789033b1e7d295cec740，与官方 v1.7 beta15 发布资产一致。帮助文字 1.3.x 和包内配置 1.6.6 为旧版本标识。内置 FullProf v7.40 Jan2021，运行环境为 Ubuntu 24.04.3、包内 Python 3.9.13。使用默认专家系统 -c 0 -a，没有运行 RL-FP 训练或推理。

初始模型与参数

使用 TCH pseudo-Voigt（Npr=7）、六项多项式背景（Nba=0）和 FullProf 内部 NCY=10。初始背景为强度第 20 百分位；晶体样品初始 U/V/W=0.01/−0.01/0.01。石墨近似模型起始 W=4。波长和 Kα 比率优先采用输入元数据；Rigaku RAW 读取 Cu Kα 波长，未提供的强度比使用 0.5。氟磷灰石采用元数据给出的 Cthm=0.7，其余用模板 0.91。缺失或非正的初始 Biso 取 0.5 Å²。未使用最终精修结果或已知相比例来初始化。

PCR 占位使用 site occupancy × multiplicity / general multiplicity。报告中的最终位点占位已经转换回 CIF 的 site occupancy。Caglioti 展宽 U/V/W 与原子 Uiso 是不同物理量，不能只因一个 Caglioti 系数为负就判结构非物理。原子 Biso 与整体 Bov 同时释放时存在参数冗余，物理审查还计算 Biso+Bov，避免仅凭负 Biso 分量作错误判断。

结果的对照用途

本批次提供了可审计的单次运行产物和明确的失败路径。可用于讨论自动选参的运行完成情况、默认专家系统的物理边界，以及低 Rwp 与结构合理性的关系。不能把六个正常退出码当作六个科学成功，也不能把输入适配错误作为 AutoFP 的算法失败。

对 DSH-XRD 的正式比较应明确任务范围：本次 AutoFP 的物相、缺陷位点和杂质候选已经由执行者提供；DSH-XRD 如果承担原始数据理解、数据库检索和模型升级，其能力范围更宽。论文既可以比较同一初始 CIF/PCR 下的精修，也可以比较各自全流程，但应分别说明，且统一 Rwp 口径。本次没有另一工具在这些样品上的冻结结果，因而没有计算相对胜负或加速比。该批次不自动证明任何系统的一般优越性。

上传提示词中明确要求 Fe2O3_Fe3O4_2ph、FE50 和 LayeredOxide 尽可能达到 R≤10。铁氧化物仅全谱复算口径达标而原生口径不达标；FE50 两种口径均不达标；层状氧化物两种口径均达标但结构不合理。LiFePO4 的低 R 值未转化为有效反位率，氟磷灰石未实现峰拟合，非晶样品未完成非晶工作流。R 阈值不单独作为发表级成功判据。

固定产物与复核方式

每个样品保存：初始 CIF、PCR、DAT、输入假设 JSON；唯一一次调用的命令、时间和 SHA-256；完整标准输出/错误日志；原生最终 PCR、PRF、OUT、SUM、PNG、参数轨迹、回滚快照与备份；静态转写的 unvalidated_final_phase_*.cif 和结构审查 JSON。

原生 PCR 是最终精修参数的权威文件。导出的最终 CIF 标注为未验证诊断产物，完整保留异常占位和热参数，没有通过修改得到“物理正确”的假结果。CIF 还记录非标准的 _autofp_phase_overall_Bov 字段；常规 CIF 软件未必使用该字段，故不能把它当作可直接发表或完全等价复现散射的结构。

正式调用结束后的原生文件清单已经再次进行稳定性与 SHA-256 校验。氟磷灰石有三个原生文件在首份 CLI 退出快照后发生字节差异；初次和最终清单都保留在该样品 attempt_001.json，最终冻结采用稳定后的文件，未增加引擎调用。用时采用外层单调时钟；原生 FullProf 文字时间与外层 UTC 相差四小时，不混用两类时间戳计算用时。

results.json 和 results.csv 包含机器可读结果，protocol.md 记录事前设置及偏差。scripts 保存准备、一次运行、冻结核验和报告生成代码。执行者未修改 AutoFP 或 FullProf 算法。原 CLI 因已单独提供，不重复装入结果包；固定版本下载地址和哈希在 SOFTWARE.json。
